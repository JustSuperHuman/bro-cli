# Parity verification

Each file here is one reviewer's verdict on a group of `PARITY.md` sections, merged back into the checklist.

Line format (one per item, in checklist order):

```
ID | STATUS | note
```

- `DONE`: the window does it (GUI code, or shared workspace logic the window reaches the same way), checked.
- `FIXED`: it was missing or wrong and the reviewer fixed it in this pass (the note says where).
- `PARTIAL`: works with a gap (the note says what's missing).
- `MISSING`: not done (the note says what it needs and where).
- `DELTA`: deliberately different (the note cites the DD-nnn or says why).
- `N/A`: doesn't apply to a window (the note says why).
