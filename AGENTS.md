# Agent instructions

- When writing copy or any prose an audience will read (UI copy, marketing and website copy, emails, posts, announcements, reports), use the humanize-writing skill.
- After every change in this repository, rebuild and install the latest Bro app before reporting completion. On Windows, build both `bro.exe` and `bro-app.exe` with `cargo build --locked --release -p bro-tui --bins`, install them to the active location on `PATH`, verify the installed hashes match the build, and check a fresh Bro process. Keep existing Bro sessions running during installation.
